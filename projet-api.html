Intégration API & SQL

Contexte du projet

Durant mon stage, j’ai été chargé de développer une application en C# permettant de récupérer automatiquement des données depuis une API externe afin d’alimenter une base de données Microsoft SQL Server.

L’objectif était de mettre à jour les informations de manière fiable et automatisée, sans saisie manuelle.

Technologies utilisées

C# (.NET) SQL Server API REST JSON

Besoins du projet

  • Récupérer automatiquement des données depuis une API externe
  • Alimenter une base de données SQL Server de manière fiable
  • Automatiser le processus sans intervention manuelle
  • Gérer les erreurs de connexion et la fiabilité des transferts
  • Assurer l'intégrité des données lors de l'import
  • Planifier l'exécution automatique de l'application
